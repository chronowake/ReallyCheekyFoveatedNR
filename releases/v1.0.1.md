# Really Cheeky Foveated NR v1.0.1

- **Fixes the Ray Reconstruction crash in Star Wars Outlaws.** Enabling RR crashed the game straight to desktop. NR and RR now run together. This may also improve NR image quality in Streamline games, which were sometimes using the previous frame's output.
- **Safer handling of bad game resources.** If a game passes a motion-vector or depth texture that doesn't fit the NR region, that frame is skipped instead of risking a GPU crash. Spider-Man 2 hits this briefly during loading.
- **Hardening.** A fault while reading NVIDIA's DLSS parameters is now logged instead of taking down the game.
- **The project builds again from source.** The test project previously failed to compile.

Tested on Star Wars Outlaws, Baldur's Gate 3, Marvel's Spider-Man 2, Hogwarts Legacy and Uncharted: Legacy of Thieves Collection.

Replace your existing `ReallyCheekyFoveatedNR.addon64` with this one. Settings carry over.

Native SteamVR / OpenVR gaze is not active in this fork; eye tracking works through the OpenXR layer.
